`https://mooc2-ans.chaoxing.com/visit/interaction?s=<token>`

| 目标 | 选择器 |
|---|---|
| 课程链接 | `a[href*=stucoursemiddle]` |

| 课程 id / 班级 id | 从 href 里取 `courseid=` `clazzid=` `cpi=` |

```js

  .filter(a => (a.innerText || '').trim())
  .map(a => ({ name: a.innerText.trim(), href: a.href }))
```

`javascript:switchM('icon-kc','https://mooc2-ans.chaoxing.com/visit/interaction?s=xxx')`
—— 抠出 URL 时**记得去掉尾部的 `%27`**（平台自己拼串的 bug）。

## 进入章节内容页 ✅

**★ 折叠章下面的 `.chapter_item` 是 `not visible` —— `click()` 会 30s 超时。**

可靠做法：在 studentcourse frame 里直接调页面自己的函数（会触发 `top.location` 跳转）：

```js
await f.evaluate(() => {
  try { window.isToOldLink = false; } catch (e) {}   // ★ 页面防重复点击的锁
  toOld('<courseId>', '<chapterId>', '<clazzid>', 0);
});
await page.waitForTimeout(8000);
```

跳转目标：

```
https://mooc1.chaoxing.com/mycourse/studentstudy
  ?chapterId=<id>&courseId=<c>&clazzid=<k>&cpi=<p>&enc=<e>&mooc2=1&hidetype=0&fanyaVersion=0&openc=<hash>
```

`toOld` 源码要点（从页面直接 `toOld.toString()` 可读）：
- `mooc1Domain = ServerHost.mooc1Domain`（= `https://mooc1.chaoxing.com`）
- 先拼 `referUrl`（studentstudy），再拼 `transferUrl`（`/mycourse/transfer?...&refer=<encoded>`），最后 `top.location = transferUrl`
- `enc` 在该函数里是**页面硬编码**的课程级 token，可从源码正则抠：`/var enc = "([^"]+)"/`

`ServerHost` 全局域名字典（`serverHost.mooc1Domain` 等）实测存在：
`moocDomain` / `hostDomain` / `mooc1Domain` / `mobilelearnDomain` / `purl` / `purlNew` / `ananasDomain` …

## 已知坑

见 `踩坑记录.md`。要点速览：

| 坑 | 解法 |
|---|---|
| `iframe.contentDocument` 读到 `null` | 用 Playwright 的 `page.frames()` + `frame.evaluate()` |
| 折叠章下的节点不动（30s 超时） | 调 `toOld()` 导航，别硬点 |
| 点「章节」用 JS `.click()` 不换页 | 用 `page.getByText(...).click()` |
| 长 JS 塞进命令行被引号转义搞坏 | 写 `.js` 文件 + `run-code --filename` |
| `run-code` 输出被代码回显淹没 | 加 `--raw` |
| `?s=` / `cpi` / `enc` 不是常量 | 从当期页面 URL 或 `toOld` 源码里抠 |
