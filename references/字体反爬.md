# 学习通字体反爬（font-cxsecret）与破解

> 状态：✅ 已实测破解，映射表**用上下文自验证过**。
> 影响面：**作业 / 章节测验的题干**（选项文本通常是干净的）。

---

## 一、现象

同一句话，**截图看正常、DOM 读出来是乱码**：

| 来源 | 内容 |
|---|---|
| 截图（视觉） | 马克思主义的理论渊源主要有（） |
| DOM `innerText` | 马噞思主噤噟理噢噣噡主噧有（） |

**逐字比对**：约一半的**常用字**被换成了形近字。
未被替换的字（马、思、主、理、有）保持原样 —— 所以不是整段加密，是**逐字替换**。

---

## 二、机制

```css
@font-face {
  font-family: font-cxsecret;
  src: url(data:application/font-ttf;charset=utf-8;base64,AAEAAAAMAIAAAwBAQkFTRRuOGNg...)
}
```

- 题干里有一个内层元素带 `style="font-family: font-cxsecret"`（外层是正常的 `CXChineseQuote`）
- 字体**以 base64 内嵌在 CSS 里**（不是外链 URL），所以 `page.route()` 拦不到、`requests` 里也看不到字体请求
- 实测该字体只有 **31 个 glyph**，码点集中在 `U+565E~U+5684` 加零星几个
- glyph 名是 `uniXXXX`（= **乱码字符自己**的码点）→ **不泄露真实字**，不能直接读表还原

### ⚠️ 映射**不是跨页面固定的**（重要更正）

同一页面**重复读取**结果一致，所以一开始误判成"固定映射"。
但**换一节内容就换一整套**：

| 节 | 混淆字符（节选） |
|---|---|
| 1.1 | `噞 噤 噟 噢 噣 噡 噧 噩 噭 噮` |
| 1.2 | `壛 壜 壗 壖 壝 垒 壞 壡 瀧 壠 壥 壤 壧 壨` |

**两次的字符集完全不重叠** → 那张 31 字映射表**只在 1.1 那一页有效**。

**结论：别指望一次建表长期复用。** 优先用下面第四章的「截图读题」。

## 三、破解流程

### 3.1 取字体

用 `scripts/crack-font-extract.js` 拿到 base64，PowerShell 解码成 `.ttf`（见脚本头注释）。

### 3.2 字形比对

用 `scripts/glyph_match.py`：把混淆字体的每个 glyph 渲染成位图，
和系统字体（msyh / simsun）里 **U+4E00–U+9FA5 全部汉字**逐一做归一化余弦相似度，取 Top-3。

```powershell
& "<bundled-python>" scripts/glyph_match.py cxsecret.ttf glyph_map.txt
```

依赖 `fontTools` 与 `Pillow`：
```powershell
& "<bundled-python>" -m pip install fonttools --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.3 ★★★ 必须用「上下文」复核，不能只信相似度

**单靠字形相似度会错**。实测反例（msyh 与 simsun 都判错）：

| 码点 | 程序判 | 正确 | 上下文依据 |
|---|---|---|---|
| `U+5662` | 纶 | **论** | 理**论** |
| `U+566B` | 劢 | **动** | 工人运**动** |
| `U+566C` | 栝 | **括** | 包**括** |
| `U+5682` | 們 | **们** | 简体语境 |

**复核办法**：把映射代回真实题干，**看句子通不通顺** —— 通顺即正确。
（这一步用语言判断，比像素相似度可靠得多。）

### 3.4 ★★★ 首选方案：截图读题（绕开字体问题）

**关键认知：不需要把题目"还原成文本"，只需要知道"该选哪个"。**

题干被混淆没关系 —— **选项文本是明文**（不混淆）。所以：

1. `page.screenshot({ path, fullPage: true })` 截整页（iframe 内容会一并渲染进去）
2. 用工具有多模态能力直接**看图读题**
3. 从 DOM 拿干净选项文本，按**内容**匹配，点对应的 `li`

**实测效果**：一次截图读完整页 4~5 题，比字形比对 + 上下文复核**又快又准**
（字形比对还会错：`纶`→论、`栢`→括、`劢`→动）。

**什么时候仍用字形比对**：需要把题干当**文本**处理时（批量导出、搜索、做题库）。
只是答题的话，截图足够。

## 四、实测映射表（31 字，已上下文验证）

★ = 程序判错、由上下文修正的字。

**用法**：读到乱码文本后，逐字查表替换；表外的字保持原样。

```js
const CXMAP = { '\u565E':'克','\u565F':'的','\u5661':'源','\u5662':'论','\u5663':'渊',
  '\u5664':'义','\u5667':'要','\u5669':'政','\u566B':'动','\u566C':'括','\u566D':'显',
  '\u566E':'力','\u5670':'三','\u5671':'割','\u5673':'是','\u5675':'不','\u5676':'思',
  '\u5677':'可','\u567A':'放','\u567B':'阶','\u567C':'产','\u567D':'为','\u567E':'马',
  '\u567F':'和','\u5681':'人','\u5682':'们','\u5683':'引','\u5684':'南','\u6C8C':'分',
  '\u74AA':'无','\u7576':'主' };
const decode = (s) => [...s].map((c) => CXMAP[c] || c).join('');
```

## 五、注意

1. **映射可能随平台改版/换课程而变** —— 若还原出的句子不通顺，重新跑 3.1–3.3 建表。
2. **只覆盖这 31 个字** —— 换一门课可能换一套字体，别当成万能表。
3. **选项文本通常正常** —— 只有题干混淆，别把干净文本也拿去替换（虽然替换表里没有的字不受影响）。
